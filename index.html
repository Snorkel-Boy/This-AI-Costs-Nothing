Why did JS Heap alone say "12 MB" earlier?

Chrome's performance.memory.usedJSHeapSize only measures standard JavaScript variables (~12–20 MB). It excludes the ~185 MB Chromium tab renderer and the WebAssembly (WASM) linear memory where ONNX neural network weights live.
